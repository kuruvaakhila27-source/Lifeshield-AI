# 🛡️ LifeShield AI

LifeShield AI is an AI-inspired safety analysis application that analyzes user-provided text and identifies potentially suspicious indicators.

## ✨ Features

- 🔍 Text-based safety analysis
- 🚨 Risk-level classification
- 📊 Risk score generation
- ⚠️ Suspicious indicator detection
- 💡 Clear analysis results

## 🛠️ Tech Stack

- Python
- Streamlit
- Regular Expressions

## 🚀 How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Run the Streamlit application.

```bash
streamlit run app.py
